## 布局 (从下往上)

```
┌─────────────────────────────────────┐
│  cue text (单词级,可点击)            │  ← 字幕区(S 控制显隐)
│  translation / 翻译未配置            │  ← 翻译区(挡位 3)
├─────────────────────────────────────┤
│  NOSUB │ Q 精听 S① D 下一句 E 速度 │ ⟳ 精听中 [Q 退出] │  ← 控制栏,永远可见
└─────────────────────────────────────┘
         ↑ bottom: 80px (高于 YouTube 控制条)
```

- 控制栏: Apple 风格毛玻璃, 圆角 14px, 高度 44px
- 字幕在控制栏**上方**, 翻译在字幕和控制栏**之间**

## S 键:三挡揭示 (全模式统一)

S 键不再是简单开关, 而是四态循环:

| S 按下次数 | 挡位 | 字幕显示 | 翻译显示 |
|---|---|---|---|
| 0 (默认) | off | 隐藏 | 隐藏 |
| 1 | initials | 首字母模式 `m____` | 隐藏 |
| 2 | words | 完整单词 | 隐藏 |
| 3 | full | 完整单词 | 显示 (无翻译时显示"翻译未配置"占位) |
| 4 → | 回到 off | 隐藏 | 隐藏 |

### Normal vs Repeat 的区别

| 模式 | 挡位 0 (off) 的表现 |
|---|---|
| **Normal** | 字幕区完全消失, 干净 |
| **Repeat** | 字幕区**固定显示占位条** (符合字幕长度的遮挡条), 等待 S 揭示 |

> 进入循环时挡位**保持不变** (不重置)
> 退出循环时挡位**保持不变** (不重置)

## 用户操作 → UI 变化

### 键盘

| 操作 | 效果 |
|---|---|
| **S** | 挡位 +1 (0→1→2→3→0) |
| **Q** | 进入精听 / 退出精听 |
| **A** | 精听中返回上一句；普通播放时不执行 |
| **D** | 进入下一句；精听中继续保持精听 |
| **E** | 播放速度循环 (1.0→0.8→0.6→1.0) |
| **Esc** | 关闭查词卡片 |

### 鼠标

| 操作 | 效果 |
|---|---|
| 点击单词 (挡位 1/2/3) | 高亮 + 弹出词典面板(字幕上方) |
| 点击 [Q 退出] | 等同按 Q |
| 拖进度条到句外 | 退出循环 |

### 视频切换

| 事件 | 效果 |
|---|---|
| SPA 切视频 | 销毁 → loading → 加载新字幕 → 恢复控制栏, 挡位重置为 0 |
