## v2.0 — 划选精听 + AI 辅助

### 划选精听（句内循环）
```
当前: 按 A → 循环整句 "hello everyone welcome back"
2.0:  鼠标划选 "welcome back" → 按 A → 只循环 600ms→1100ms
```

技术依赖：
- json3 解析存 seg 级时间戳（`segments[{tOffsetMs, text}]`）
- Cue 加 `segments[]` 字段
- subtitle-display 框选交互
- PlaybackEngine 支持自定义起止时间

### 单词问 AI
```
点击单词 → 卡片新增 AI 分析区
  "这个词在这句话里是什么意思？"
  "这里的用法跟常见用法有什么不同？"
```

### 划选问 AI
```
框选一段 → 右键/按钮 → AI 解释
  "这是什么语法结构？"
  "这里为什么用这个时态？"
  "这几个词之间的连读怎么读？"
```

### AI 层设计
```
AIExplainer.explain({type, word, cueText, selection})
  → Provider 链
    → 本地规则匹配（连读标注：free）
    → 用户自己的 API Key（Gemini/OpenAI）
    → 服务端代理（可选）
```

## v2.5 — 连读标注 + 弱点记录

### 连读标注
```
"I want to go"  →  字幕下方显示 "wanna"
"What did you say" → "whadja say"
"I'm going to" → "I'm gonna"
```

数据层：
- 连读词典文件（~200 条常见连读）
- 字符串匹配，零 API 调用
- 字幕内嵌浅色标注，hover 显示音标

### 个人弱点记录
- 某句循环了 N 遍 → 标记为"难句"
- 某词查了多次 → 下次遇到加标记"你查过"
- 某个连读类型反复循环 → 推荐相关教程

### 语速热点图
- 进度条旁标注每句的实际语速（wpm）
- 语速超阈值（e.g. >180 wpm）的句子标红
- 用户可跳过或专门攻克

## v3.0 — 主动听写 + 难度自适应

### 填空模式
- 自动识别句中"信息密集点"（动词、否定、数字）
- 对应位置变空白 → 听 → 按一下显示答案

### 听写对比
- 盲听 3 遍 → 打出听到的内容
- nosub 标出差异 → 集中在连读/弱读位置

### 难度自适应推荐
- 记录用户历史（循环次数、查词频率）
- 推荐匹配当前水平的视频
- 逐步提高难度（语速、口音、词汇量）

## v4.0 — 沉浸式训练

### TTS 口音变体
```
同一句话，生成 10 个版本:
  - 美音男声（清晰）
  - 美音女声（正常语速）
  - 英音 RP（清晰）
  - 澳音（含混）
  - 印度英语
  - 背景咖啡厅噪音
  - 电话音质（300Hz-3kHz）
```

### 背景音移植
- 提取纯人声 → 先听干净的 → 再听带噪音的

### 多端支持
- Netflix 字幕
- 本地视频文件
- 播客
