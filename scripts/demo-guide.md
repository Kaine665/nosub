# nosub 演示视频录制指南

## 方案：脚本驱动 + 手动录屏

### 1. 准备
- Chrome 加载 nosub 扩展（`chrome://extensions` → 加载 `dist/`）
- 选一个有英文字幕的 YouTube 视频（推荐：TED 演讲，发音清晰）
- 安装录屏软件：
  - Windows: OBS Studio（免费，最专业）
  - Mac: QuickTime（自带）或 OBS
  - 在线: Loom（免费，直接导出）

### 2. 录制流程

1. 打开 YouTube 视频
2. 按 F12 打开 Console
3. **开始录屏**
4. 粘贴 `scripts/demo-playback.js` 的内容到 Console，回车
5. 脚本会：
   - 屏幕中央显示大字提示（"按 S — 显示字幕"）
   - 自动模拟按键
   - 每步停留 2-4 秒供观看/截图
6. 约 45 秒后自动结束
7. **停止录屏**

### 3. 演示步骤（脚本自动执行）

| 时间 | 操作 | 画面 |
|---|---|---|
| 0s | 开场 | "nosub 演示" |
| 3s | 按 S | 字幕出现（单词级） |
| 6s | 按 A | 进入循环，字幕遮挡 |
| 10s | 循环中 | 听几遍 |
| 13s | 按 S | 揭示字幕 |
| 16s | 按 S | 加翻译 |
| 20s | 按 A | 前一句（自动遮挡） |
| 23s | 按 D | 退出循环 |
| 26s | 按 E | 0.8× 慢速 |
| 29s | 按 E | 0.6× 更慢 |
| 32s | 按 E | 恢复 1× |
| 35s | 结束 | "nosub" |

### 4. 截图建议（Chrome Web Store 用）

录完后，在以下场景暂停截图（1280×800）：

- 控制栏展示（底部 NOSUB 条）
- 字幕开启（完整单词级）
- 首字母模式（遮挡）
- 查词弹窗（点击单词后）
- 循环指示器（红色脉冲点）
- 全屏模式
