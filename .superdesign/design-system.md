# nosub Design System

**Product:** YouTube focused-listening Chrome extension (单句循环 / 遮字幕 / 点词查义)

**Visual language:** Dark frosted glass over video. Minimal, keyboard-first, Apple-like control chrome. Dictionary card should feel like a quiet study tool — not a flashy flashcard app.

**Constraints**
- Floats over busy YouTube video — keep contrast high, footprint compact (~380px wide)
- Must show: headword, UK/US IPA + speak buttons, POS + glosses, 1–2 short examples
- Chinese UI uses labels 释义 / 例句
- Prefer readable type over decoration; avoid purple gradients / neon glow / heavy cards-in-cards

**Reference sample content (whenever)**
- Word: whenever
- UK `/wəˈnɛvə/` · US `/hwəˈnɛvɚ/`
- Senses: conj 无论何时 · conj 每当
- Examples: "Visit whenever you want to." / "Tomorrow I'll get up whenever the sun rises."
